# Registan — дизайн-система блога

Язык взят из двух источников: керамика самаркандских медресе (цвет) и книжная
полоса (структура). Никаких карточек с тенями и скруглений — только набор,
волосяные линии и один акцент.

## Токены

Определены в `src/index.css` как CSS-переменные и подхвачены Tailwind
в `tailwind.config.js`. Переменные переключаются целиком при добавлении
класса `.dark` на `<html>` — поэтому `!important`-правил в теме почти нет.

| Роль | День | Ночь | Где применяется |
|---|---|---|---|
| `--paper` | `#F5EFE4` | `#100F0D` | фон страницы |
| `--paper-deep` | `#EDE4D3` | `#1A1815` | подвал, врезки, поля |
| `--ink` | `#14110E` | `#F0E9DC` | текст, кнопки, линейки |
| `--ink-soft` | `#4E453A` | `#A39684` | второстепенный текст |
| `--ink-faint` | `#8A7C68` | `#6F6252` | колонцифры, отточие |
| `--tile` | `#0F6E76` | `#35B3B8` | единственный акцент |
| `--saffron` | `#D4A017` | `#E9BE4A` | выделение, курсор выбора |
| `--terra` | `#B4472B` | `#D4694A` | ошибки |

Шкалы `gray` и `blue` в конфиге Tailwind **переопределены**: старый код
продолжает писать `bg-gray-50` и `text-blue-600`, но получает новую палитру
без правок в компонентах.

## Шрифты

Все три содержат кириллицу — для русскоязычного журнала это условие,
а не пожелание. Fraunces и Newsreader пришлось отвергнуть именно поэтому:
на русском тексте браузер молча подставляет системный шрифт.

| Гарнитура | Роль | Класс |
|---|---|---|
| Literata | заголовки, акциденция, цитаты | `.display`, `font-display` |
| Golos Text | основной текст | по умолчанию, `font-sans` |
| JetBrains Mono | метаданные, цифры, код | `.label`, `.folio`, `font-mono` |

Подключаются в `index.html` через `<link>`, не через `@import` в CSS —
`@import` блокирует отрисовку.

## Компоненты

Описаны в `@layer components` внутри `src/index.css`:

- `.index-row` — строка указателя материалов: колонцифра, заголовок,
  отточие `.leader`, метаданные. При наведении слева выезжает изразцовая полоса.
- `.label` / `.folio` — моноширинные метки и порядковые номера.
- `.display` — крупный редакционный заголовок с осью `opsz`.
- `.btn-primary` / `.btn-secondary` — кнопки со смещением на 3 px вместо тени.
- `.link-wipe` — подчёркивание, «протягивающееся» слева направо.
- `.rule-t` / `.rule-b` / `.rule-l` — волосяные линии вместо рамок.
- `.ornament` — гирих-разделитель разделов.
- `.article-body` — полоса статьи: мера строки 66 знаков, буквица у первого абзаца.

Радиус скругления по всей шкале сведён к 1–6 px (`borderRadius` в конфиге) —
этого достаточно, чтобы убрать «пузырьковый» вид со всех страниц разом.

## Ассеты

Знак — восьмиконечная звезда (руб-эль-хизб), `public/logo.svg`.
Растровые производные и социальная карточка генерируются:

```bash
npm run assets    # og-image.png + иконки приложения из logo.svg
npm run sitemap   # sitemap.xml из опубликованных постов
```

Исходник карточки — `public/og-image.html`; правится он, а не PNG.

## Движение

Ступенчатое появление при загрузке (`.slide-up` + `.stagger-1…5`), протяжка
подчёркивания, выезд полосы у строки указателя. Всё отключается через
`prefers-reduced-motion`.
